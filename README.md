# Basti Ki Pathshala – NGO Website

A responsive, React + Bootstrap-based website for **Basti Ki Pathshala Foundation**, an NGO dedicated to providing free education to children in urban slums.

## 🌐 Live Demo

[View Website](https://mahimakathpal.github.io/)

## 🚀 Features

- ✨ Modern React UI using Bootstrap
- 📱 Fully responsive design
- 🔁 React Router-based navigation
- 🧒 About, Programs, Impact, Volunteer, Donate Pages
- 🔼 Scroll-to-top button
- 🔒 Custom favicon
- 📄 SEO-friendly content

## 🛠️ Technologies Used

- React.js
- Bootstrap 5
- React Router DOM
- gh-pages for deployment
